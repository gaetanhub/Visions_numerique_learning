# Site web — Vision Numérique (Chapitre 1)

Ce dépôt contient un front-end React + Vite + TypeScript pour la théorie du chapitre 1.

## Installation

```bash
npm install
```

## Lancer en développement

```bash
npm run dev
```

## Build production

```bash
npm run build
```

## Assets de cours

Les figures utilisées par l'application sont servies depuis `public/course-assets/chapter-01/introduction`.
Elles sont copiées dans `dist/course-assets/chapter-01/introduction` au moment du build Vite.
